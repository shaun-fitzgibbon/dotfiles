# Global agent instructions

## Git commits

- Always use Conventional Commits: `type(scope): description`.
- Allowed types: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert.
- Scope is optional. Use an imperative, concise description.
- Mark breaking changes with `!` after the type or scope and explain them in a `BREAKING CHANGE:` footer.
- Example: `fix(shell): prioritize fnm-managed Node`.
